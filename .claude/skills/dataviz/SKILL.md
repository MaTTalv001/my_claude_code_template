# グラフ作成

## 1. まず「何を言いたいか」を 1 文で決める

タイトルは結論を書く（例: ×「月別売上」 ○「9 月は前年比 +12%、新規顧客が牽引」）。

## 2. 種類の選び方

| 伝えたいこと | 使う | 避ける |
| --- | --- | --- |
| 時系列の推移 | 折れ線 | 3D・面グラフの多系列重ね |
| 項目の大小比較 | 横棒（降順ソート） | 円グラフ（5 項目超） |
| 構成比 | 100% 積み上げ棒 / 項目が少なければ円 | ドーナツの多用 |
| 2 変数の関係 | 散布図 | 二軸グラフ（誤読を招く） |
| 単一の重要指標 | 数値タイル（大きな数字＋前期比） | ゲージ |

## 3. 見た目のルール

- 色はブランドトークン（`.claude/rules/frontend.md`）から取る。強調したい系列だけ `primary`、他はグレー
- 系列は 5 つまで。超える場合は上位＋「その他」にまとめる
- 凡例よりも線の端に直接ラベルを置く。目盛り線は薄く、枠線は消す
- 縦軸は棒グラフなら 0 始まり。単位は軸ラベルかタイトルに書く
- 数値は桁区切り・単位（千円、%）を揃える

## 4. 実装メモ

- **Python（資料用の静止画）**: matplotlib。日本語は `japanize-matplotlib` か `plt.rcParams["font.family"] = "Noto Sans CJK JP"`。`dpi=200`、`bbox_inches="tight"` で PNG を出力し、pptx/docx に貼る
- **Python（探索・HTML レポート）**: plotly。`fig.write_html(..., include_plotlyjs="cdn")`
- **React 画面**: Recharts。色はハードコードせず CSS 変数を参照する
- データ加工は pandas で行い、グラフ生成スクリプトとして残す（再実行で同じ図が出ること）
